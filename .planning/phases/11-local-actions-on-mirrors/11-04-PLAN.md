## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HA Store JSON to trusted local execution | Local disk data is parsed before becoming runnable action input |
| Main Store to local Store | Older code may rewrite only the main file and must not erase overlays |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-11-10 | Denial of service | Immediate local Store save | medium | mitigate | Failed save retains prior active/durable snapshot and returns an error; manager will not acknowledge it |
| T-11-11 | Information disclosure | Test Store key collision | medium | mitigate | Every InstanceFactory manager receives a distinct local key and isolation test |
