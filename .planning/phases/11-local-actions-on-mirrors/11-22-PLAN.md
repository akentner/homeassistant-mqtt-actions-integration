<objective>
Fix review finding WR-04. `async_local_action_device_count` returns `manager.local_action_counts().devices` for a loaded hub. That is `0` when the local load was refused, because `_local_records = ()`. For an unloaded hub, a read error also maps to `0`. Either way, `async_remove_local_state` then deletes the file unconditionally. In the downgrade scenario the README warns about, the settings text tells the user that removing the hub "deletes the local actions of 0 devices" while it deletes all of them.

Owner decision 2026-10-21 (locked): return None (unknown) when the Store could not be read. Expose a readability flag from the Manager for a loaded hub. Show a dedicated warning text in English and German, such as "the saved local actions cannot be read and will be deleted".

Purpose: the removal warning of D-08 must never under-report.
Output: Manager flag and count API, a dedicated options step with en/de texts, regression tests, README and release-notes text, and disposition row WR-04 = fixed. After this plan, all four review warnings are fixed.
</objective>
