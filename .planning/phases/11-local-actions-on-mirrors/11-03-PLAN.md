<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote owner actions and trusted local actions inside one Script | Two trust levels share scheduler and variables but require different validation/guard rules |
| Core trace to local Repairs state | Ephemeral internal trace must yield bounded outcomes without content persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-05 | Elevation of privilege | Trust-level mixing in one Script | high | mitigate | Explicit EffectiveTriggerPlan branches; validate separately; apply denylist and GuardedTemplate only to owner; identical local call test remains allowed (D-02, D-23) |
| T-11-06 | Tampering | Immutable owner DeviceSpec | high | mitigate | Deep-copy tests and byte-identical dispatcher/hash/adoption invariants prevent local overlays from rewriting owner content |
| T-11-07 | Repudiation | Per-branch outcome reducer | high | mitigate | Task-local trace paths and conservative outcome tests cover masked/continued/cancelled/superseded executions |
| T-11-08 | Information disclosure | Core trace variables | medium | mitigate | Reduce immediately to bounded status/error and discard the collector; never persist or diagnose raw trace data |
| T-11-SC | Tampering | npm/pip/cargo installs | low | accept | No package installation or upgrade occurs |
</threat_model>
