## Phase Goal

**As a** user running several HA instances, **I want** to re-trigger actions, see who is connected and recover devices, **so that** I can operate the setup with confidence.

This plan's slice: the approval stays honest before the operations tools arrive. What a user approves is exactly what can run, including how often and in which mode (Phase 3 finding WR-04).

<objective>
Bind `run_mode`, `breaker_max_runs` and `breaker_window` into `actions_hash` so that changing them needs re-approval like changing the actions, show them in the approval dialog, and make the README sentence about the hash true (D-16).

Purpose: closes WR-04 of Phase 3. Without it a forger of the config topic could switch an approved mirror to restart mode or raise its breaker limit to 100 runs per second after approval. The hash is computed locally from received content, so there is no cross-version wire problem; existing approvals lapse once and Repairs asks again.

Output: `document.py`, `trust.py`, `repairs.py`, both translation files, one README sentence and the tests that pinned the old behavior. Implements D-16.
</objective>

## Assumptions and defaults (visible, not silent; none are locked decisions, confirm at review)

- **Naming:** the new run/observe/disabled concept of D-14 is a different thing from the existing `run_mode` (serial or restart). This plan only touches the existing `run_mode`; later plans use `MODE_*` names for D-14.
- **Requirement mapping:** D-16 sits under SYN-09 in CONTEXT, so this plan carries SYN-09 although it does not add the per-device mode.
- **No migration code:** the stored approval is a hash string; after the upgrade no mirror matches it, `_async_refresh_mirror_script` leaves the mirror without a Script and `_sync_approval_issues` raises a request for each at start. The notice is the Repairs requests, the dialog and a README sentence. No release exists yet (no git tag), so the blast radius is the developer's own instances.
- **Stale approval entries** of lapsed mirrors stay in the Store as they do today when an owner changes actions; they are dropped with the mirror.
- **Placeholders:** `run_mode` is rendered as the stored word (`serial` or `restart`), the limits as plain numbers.
- **No SPEC.md exists; the spec-less probe was skipped.** The prohibitions above were authored by the planner from RESEARCH Pattern 5 and CONTEXT D-16.
