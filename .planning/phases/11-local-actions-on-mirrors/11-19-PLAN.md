<objective>
Fix review finding WR-02. Only a proven success of the named trigger (`_clear_local_failure_naming` from `async_report_local_outcome`) or removal of its record clears `local_action_failed`. Suppose the user reacts to a failure by muting the trigger (replacement with `[]`) or by emptying its additive actions. Then the trigger never produces a local outcome again, the record still exists, and the stale issue can only go by removing the customization. For a mute, that brings back the owner actions the user deliberately suppressed.

Owner decision 2026-10-21 (locked): when a saved record has no local actions, clear the issue that names that identity. A record without local actions cannot fail locally any more.

Purpose: let the user resolve the issue in the way they chose, without undoing the mute (D-19 amended, recorded in 11-CONTEXT.md by Plan 11-23).
Output: the one-line Manager change with regression tests, updated en/de issue text, docs and release-notes draft, and disposition row WR-02 = fixed.
</objective>
