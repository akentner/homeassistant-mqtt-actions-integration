</objective>

## Decisions this plan implements (visible, not silent)

- **Roadmap order and D-09/D-10:** the ordering spy test comes before the move; spies sit only on seams that stay where they are (the collaborators, `DiscoveryPublisher`, the `takeover` module functions, Manager methods that do not move), so plan 10-04 needs no edit of this test.
- **Research Pitfall 8 (mutation check per moved function):** run twice, here before the move and in plan 10-04 after it. Survivors are pinned here, so the post-move run can require every mutant killed without touching tests (D-10).
- **Planner decision:** the timers are proven by behavior (the catch and the cutover check run only after their delay), not by spying on `async_call_later`, which moves with the code.
