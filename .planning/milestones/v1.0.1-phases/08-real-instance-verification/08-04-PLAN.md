## Phase Goal

The Discovery export is verified on real instances: it is disabled by default and has no buttons, the core MQTT prefix yields only disabled duplicates, and switching it off clears its topics (ROADMAP Phase 8 success criterion 4).

<objective>

Purpose: UAT-04 was skipped in Phase 5. The test ACL has no row for the export prefix, so an unprepared run would find no topic and look like a defect (Pitfall 2). The core-prefix duplicates exist only until the next start, because the replay catch also removes them (Pitfall 4): they must be observed first, restarted second.

Output: `uat-04` evidence, block 4 recorded, the observation about the restart cleanup, `run-all-scripted.sh`, `gate-after-scripted.txt`.
</objective>
