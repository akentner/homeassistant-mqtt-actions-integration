## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] mosq probe raced the broker listener after the recovery start**
- **Found during:** Task 1, step 3.
- **Issue:** The first probe ran right after `podman start mosq` reported running=true. It hit the broker before its listener was open (rc=1), and the script stopped. At that point nothing had been written to the repository and nothing had been stopped or backed up.
- **Fix:** The probe now retries up to 10 times, 2 s apart. The re-run passed the found states (saved from the first attempt's output) and the old mosq StartedAt as inputs, so `bench-recovery.txt` shows the state as found, not the state after the restart.
- **Files modified:** none in the repository (scratchpad script only).
- **Verification:** the probe returned rc=27 (connected, no retained message), and `bench-recovery.txt` shows `mosq_started_at_old: 2026-10-12 03:46:21…` and `new: 2026-10-15 00:23:51…`.

**2. [Rule 1 - Bug] ANSI color codes in the UAT-04 guard-log projection**
- **Found during:** Task 3, step 5a.
- **Issue:** `podman logs` of the HA containers emits colored lines, so the timestamp-and-text reduction left `ESC[32m` codes in `guard-log-{a,b}.txt`.
- **Fix:** Both files were regenerated from `podman logs --since <run start> --until <observation restart>` with the ANSI codes stripped. The window now ends at the restart, so it holds the UAT-04 run only. The counts are unchanged (2 per instance).
- **Files modified:** `uat-04/guard-log-a.txt`, `uat-04/guard-log-b.txt` (before commit `f009ff8`).
- **Verification:** `cat -v` shows no escape sequences, and the evidence scan prints PASS.
