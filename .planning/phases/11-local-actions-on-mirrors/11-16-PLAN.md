<objective>
Close gap G-03 (ledger finding F-03). The hub config flow creates the entry without touching a leftover `mqtt_actions.local_actions` file, and the Manager loads whatever that file holds. Removing the integration on 1.0.1, or a failed delete on 1.1 (which is only logged), leaves the file behind. Its trusted local actions then run on a new hub without the user having set them up there.

Purpose: D-08 says removing the integration deletes its local Store, and D-02 trusts local actions only because the instance's own user wrote them. Because the hub is a single config entry, no hub exists at the moment a new one is created, and that moment is where the leftover file must go.
Output: the leftover removal in the hub flow, with a guard and a failure path, a bilingual base error, one README sentence and ledger row F-03 FIXED.
