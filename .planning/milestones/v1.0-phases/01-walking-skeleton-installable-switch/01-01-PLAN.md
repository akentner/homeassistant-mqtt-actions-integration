## Phase Goal

**As a** Home Assistant user, **I want to** create a Switch device whose MQTT state changes run my configured actions, **so that** I need no YAML automation.

This plan's slice: the toolchain every later slice is built and verified with (uv, Ruff, pytest-homeassistant-custom-component), gated behind one human package-legitimacy check.

<objective>
Gate the first package install behind a single human legitimacy check, then create the Python tooling scaffold (uv project, Ruff config, PHACC test harness) that Plans 01-02 to 01-06 run on.

Purpose: research flagged three dev tools as SUS because their latest releases are days old and download data is unavailable (age, release history and source repositories were checked independently). The protocol requires a human confirmation before the first install. The integration itself has no runtime dependencies, so this is the only supply-chain surface of the phase (threat T-01-SC).

Output: pyproject.toml, uv.lock, .ruff.toml, .gitignore, tests/conftest.py and tests/test_toolchain.py, verified by `uv sync --locked`, pytest, Ruff check and Ruff format check.
</objective>

Set `[tool.uv] package = false` because this repository is a config repo, not an installable wheel. Set `[tool.pytest.ini_options]` with `asyncio_mode = "auto"` and `testpaths = ["tests"]`.

    3. Write `.ruff.toml`. Start from the ludeeus integration_blueprint file (fetch https://raw.githubusercontent.com/ludeeus/integration_blueprint/main/.ruff.toml; if offline use target-version py314, lint select ALL and ignore ANN401, COM812, D203, D212, ISC001). Then set `target-version = "py314"` and `line-length = 120`, add `CPY001` to the lint ignore list, and add a `[lint.per-file-ignores]` entry for `tests/**` with S101, ANN, D, ARG, PLR2004, PLC0415, SLF001, PT018 and FBT (research Pitfall 14: without these the blueprint config produced 113 findings on the prototype).

Write tests/conftest.py with an autouse fixture named `auto_enable_custom_integrations` that requests PHACC's `enable_custom_integrations` fixture, and a fixture named `expected_lingering_timers` returning True. The mocked paho client never fires the socket-close callback that cancels the MQTT misc-loop timer, so without this override every test using the MQTT mock fails at teardown (research Pitfall 6).
    5. Write `.gitignore` covering `.venv/`, `__pycache__/`, `*.pyc`, `.pytest_cache/`, `.ruff_cache/`, `.coverage`, `htmlcov/`, and the untracked research cache directory under `.planning/research/` (threat T-01-02).

Write tests/test_toolchain.py with four tests: `test_python_floor` (sys.version_info >= (3, 14, 2)), `test_home_assistant_floor` (parse `homeassistant.const.__version__` into an integer tuple and require >= (2026, 9, 0), a tuple comparison so later Dependabot bumps to 2026.10 keep passing), `test_probatio_importable` (import probatio succeeds, per the stack rule that validation uses probatio), and an async `test_hass_fixture_boots` using the `hass` fixture that asserts `hass.is_running`.
    7. Run `uv run ruff format .` once so the format check passes, then run the verification commands.
  </action>
