## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unapproved owner document to trusted local scheduler | Remote execution metadata cannot govern local work until exact approval |
| Flow/service mutation to durable local Store | Untrusted/stale UI input crosses Manager validation and lock |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-12 | Elevation of privilege | EffectivePolicy | high | mitigate | Fixed false/serial/5/10/10 policy until exact owner hash eligibility; one snapshot feeds tracker, breaker and Script |
| T-11-13 | Tampering | Manager local mutation API | high | mitigate | Recheck identity under lock, validate, immediate-save candidate, then swap/rebuild; failed-save tests |
| T-11-14 | Denial of service | Concurrent edit/approval/rebuild | medium | mitigate | One Manager lock and immutable generation snapshot prevent mixed policies and duplicate records |
| T-11-15 | Repudiation | Breaker release on edit | medium | mitigate | Only durably successful target-device edits release trip; tests prove failed/stale edits do not |
| T-11-SC | Tampering | npm/pip/cargo installs | low | accept | No package installation or upgrade |
