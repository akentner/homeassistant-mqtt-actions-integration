## Phase Goal

**As a** user running several HA instances, **I want** to re-trigger actions, see who is connected and recover devices, **so that** I can operate the setup with confidence.

This plan's slice: the first admin tools. A user can resync everything this instance owns from a service call and take a backup of the owned devices as JSON or as a file.

Output: `services.py`, `services.yaml`, `portability.py` (export part), `CONFIG_SCHEMA` and `async_setup`, translations in English and German and tests. Implements D-11 (export), D-12 and the post-research decision on the service field name `device_id`.
</objective>

## Assumptions and defaults (visible, not silent; none are locked decisions, confirm at review)

- **Admin only (assumption A8):** every service is registered with `async_register_admin_service`; export returns actions, resync and the later services change ownership or execution, so a non-admin user must not call them. All services support an optional response (`SupportsResponse.OPTIONAL`); resync answers `{"resynced": true}`.
- **Field name:** `device_id` (user choice) is the field of every service that names a device. It holds the Home Assistant registry id of a device selected with a `device` selector (`integration: mqtt_actions`); it is an instance-local value and is never part of synced content. The docs plan reconciles the project rule against `device_id` targets in shipped examples (field allowed, targets not).
- **Export file location (assumption A7, narrower than "under /config" of D-11):** `<config dir>/mqtt_actions/<name>`, never `www` (which is served unauthenticated) and never an arbitrary path; the allowlist of core is deliberately not used. The user passes only a name matching `[A-Za-z0-9][A-Za-z0-9._-]{0,63}\.json`.
- **Response shape (Claude's discretion):** `{"export": <document>, "file": <"mqtt_actions/<name>" or null>}` where the document is `{"format": "mqtt_actions_export", "export_version": 1, "devices": [<content>, ...]}`.
- **Selection:** the optional field `device_id` accepts a list of devices; empty or missing means all owned devices. Only owned devices can be exported; a mirror, the hub device and a device of another integration raise a translated error.
- **Constants:** `SERVICE_RESYNC`, `SERVICE_EXPORT_DEVICES`, `SERVICE_IMPORT_DEVICES` (the last for plan 04-09), `EXPORT_FORMAT`, `EXPORT_VERSION`, `EXPORT_DIRECTORY` in `const.py`; the file name pattern lives in `portability.py`.
- **Error texts:** every translated error carries only fixed text and plain placeholders (a count or a code), never action content.
- **No SPEC.md exists; the spec-less probe was skipped.** The prohibitions above were authored by the planner from RESEARCH Patterns 6 and 8 and the post-research decisions.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service caller to manager | Any Home Assistant user could try to call a service |
| File name to filesystem | The export file name is user input that reaches a path |
| Export file to the outside | The file contains actions and may be copied or served |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-31 | Elevation of privilege | a non-admin user calls resync or export | high | mitigate | Every service is registered with `async_register_admin_service`; `test_resync_service_is_admin_only` and `test_export_is_admin_only` |
| T-04-32 | Tampering | path traversal or symlink through the export file name | high | mitigate | A bare name matching a full-match pattern, a fixed directory from `hass.config.path`, a refused symlink target and an atomic replace; `test_export_file_name_rules`, `test_write_export_refuses_a_symlink` |
| T-04-33 | Information disclosure | export file readable by other users or served by the web server | medium | mitigate | Directory 0700 and file 0600 under `<config>/mqtt_actions/`, never below `www`; the core external-dirs allowlist is not used |
| T-04-34 | Information disclosure | actions in the export may contain secrets | medium | accept | Admin-only call, private file, documented in the operations page; the export holds what the administrator authored |
| T-04-35 | Denial of service | resync flood through the service | medium | mitigate | The shared `Manager.async_resync` cooldown raises a translated error on a repeat call |
| T-04-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs nothing |
