## Decisions this plan implements (visible, not silent)

- **D-04:** the owner pushes main first, and Claude checks with `gh run list` that ci.yml and validate.yml are green on the bump SHA. The tag push comes in plan 09-04, after the bench.
- **D-01:** only the bump SHA and its ancestors go to origin/main here. Local main keeps its .planning commits until the owner pushes them later, which is not a gate.
- **Planner decision (documented):** the push is a refspec push of the exact bump SHA, because local main carries evidence commits on top of it. A red CI or Validate run is never re-run by Claude. The owner decides between a re-run of an infrastructure failure (runner or network) and a Phase 9.1 fix.
