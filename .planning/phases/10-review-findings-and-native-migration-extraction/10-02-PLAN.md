## Decisions this plan implements (visible, not silent)

- **D-11:** `tests/helpers.py`, public names, no leading underscore. After this plan no test module imports from another `test_*` module.
- **Planner decision (names):** a public name must not shadow anything in a consuming module: many tests assign `manager = ...`, `entity_id = ...`, `published = ...` and `deliver = ...`, and a helper of the same name would turn those calls into UnboundLocalError. The default names are listed in the action of each task; before using a name the executor greps every consuming module for an assignment, a parameter or a definition of that name, and picks another descriptive name when one exists.
- **Planner decision (scope):** a helper moves when another module imports it, together with the module-level names its body uses from the same module. Where a private helper is an exact copy of a moved one and review IN-02 names it (`_mqtt_device` in tests/test_export_guard_receiver.py equals `_mqtt_device_of` of tests/test_native_start.py), the copy goes and the moved helper is used. Other private helpers stay where they are. `_replay` of tests/test_native_replay.py moves as well although nobody imports it yet: plan 10-07 needs it (interface first).
- **D-10 is not in force here** (it governs the move plan 10-04); this plan changes test files only, but it keeps every assertion and the test count, so the move plan starts from an unchanged suite.

<assumption_delta_decision>
Detector: `assumption-delta` fired on "another" in "imports private helpers from another test module" (pluralization). The noun that is now primary is the test module that defines a helper. Decision: `no-change`. Rationale: the phrase describes test layout (who may import from whom), not an identity model of the product; no product noun gains a second instance.
</assumption_delta_decision>
