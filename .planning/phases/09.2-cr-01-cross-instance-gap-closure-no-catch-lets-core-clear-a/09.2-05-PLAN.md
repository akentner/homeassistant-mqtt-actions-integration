## Decisions this plan implements (visible, not silent)

- **D-14, 09.1 D-15 and the Phase 9 D-04 amendment:** the owner pushes main first, with the refspec of FIX, then dispatches both workflows. CI evidence counts with event push or workflow_dispatch, and headSha must equal FIX exactly.
- **Reversibility (REVERSIBILITY_GATES on): the push of main is one-way** (only a force push could undo it), so a `checkpoint:decision` (Task 1) precedes the owner's push (Task 2). The heartbeat key `kept_legacy` (D-01, costly) is named in that decision: after this push a rename needs another FIX and full re-run, after the tag it breaks the wire contract between versions. The tag stays in plan 09-04 with its own decision.
- **Gap rule:** a red run stops the phase before the bench and goes to the owner; a fix would move FIX and restart at plan 09.2-04.
